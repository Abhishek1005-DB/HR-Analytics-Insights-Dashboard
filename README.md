# People Insights Dashboard

This Power BI project presents a People Insights dashboard designed to analyze workforce composition, employee movement, grade distribution, salary patterns, and workforce trends using HR data.
​

# Project Overview
- The dashboard is built from an employee dataset containing fields such as Employee ID, Birthday, Gender ID, BU ID, Grade ID, Type ID, Salary, Start Date, End Date, Age, and Tenure.  
​- It provides a clear HR analytics view to support workforce planning, employee monitoring, and data-driven decision-making.
​

# Dashboard Features

- Headcount overview with employment type breakdown.
- Gender composition analysis with average age and average tenure insights.
- Department movement tracking across business units.
- Staff pyramid visualization by grade levels.
- Monthly workforce trend analysis comparing selected year and prior year.
- Salary distribution insights across departments and groups.​

# Tools Used

- Power BI for data visualization and dashboard development.
- Microsoft Excel dataset as the data source.
-  Power Query for data cleaning and transformation.

# DAX for calculated measures and KPIs.

Key Metrics Covered
Total headcount.
Gender split and average tenure.
Average employee age.
Department movement analysis.
Staff grade distribution.
Salary distribution by department.
​

# Business Value

This dashboard helps HR teams monitor workforce structure, identify hiring and movement trends, evaluate salary spread, and support strategic people management decisions.

It can be used for HR reporting, management review, and workforce planning presentations.
